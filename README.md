⚡ Dayflow HRMS

Every workday, perfectly aligned.

Dayflow is a lightweight, single-file Human Resource Management System (HRMS) built entirely with vanilla HTML, CSS, and JavaScript — no build tools, no backend, no dependencies. It runs directly in the browser and demonstrates a full HR workflow: authentication, attendance, leave management, payroll, employee wellbeing tracking, analytics, and an AI-style HR chat assistant.

⚠️ Demo / prototype project. All data lives in an in-memory JavaScript object and resets on page refresh. There is no real backend, database, or authentication security — see Limitations before using this for anything beyond a demo.

Features
Admin (HR)
📊 Command Center — workforce overview, present-today count, pending leave count, monthly payroll total
👥 Employee Management — add employees, view profiles
📅 Attendance — view all check-in/check-out records
🏖️ Leave Approval — approve or reject pending leave requests
💰 Payroll — edit salary structure (basic, allowance, deduction) per employee
❤️ Wellbeing Radar — flags employees who may need a manager check-in based on leave balance and attendance patterns
🧠 Leave Intelligence — leave utilization insights and team availability
📈 Analytics — headcount, approval rate, payroll totals, department breakdown, leave pipeline
🔔 Notifications — system-generated alerts
Employee
🏠 Dashboard — personal snapshot: today's status, leave balance, net salary, recent alerts
👤 My Profile — view and update contact details
📅 Attendance — check in / check out, weekly attendance table
🏖️ My Leave — apply for leave (paid/sick/unpaid), track request status
💰 Salary Slip — auto-generated monthly slip with print/save option
❤️ Wellbeing Radar — personal wellbeing indicator and recommendation
🧠 Leave Intelligence — personal leave usage stats
🤖 AI HR Copilot — rule-based chat assistant answering questions about attendance, leave, salary, wellbeing, and reports
🔔 Notifications — personal alert feed

Tech Stack
Plain HTML5 and CSS3 (flexbox/grid, no framework)
Vanilla JavaScript (no libraries, no bundler)
Single-page, client-side-rendered app — the entire UI is generated by re-rendering an in-memory state object into #root

This project is meant as a UI/UX prototype or teaching example, not a production HR system:

No persistence — all data (employees, attendance, leaves, notifications) is stored in memory and lost on refresh
No real security — passwords are stored and compared in plain text in client-side code; anyone can view credentials via browser dev tools
No backend/API — there is no server, database, or validation layer
Basic browser prompts — some flows (e.g., adding an employee, editing salary) use prompt()/alert() dialogs rather than proper forms
Simulated "AI" — the HR Copilot uses simple keyword matching, not a real language model
